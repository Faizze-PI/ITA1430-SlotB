# Ethical Hacking Laboratory (ITA1430)

Welcome to the official lab repository for **ITA1430: Ethical Hacking Laboratory**.

## Directory Structure

* [**`Programs/`**](./Programs/) - Contains all 25 laboratory programs and scripts organized in sequential order.
* [**`outputs/`**](./outputs/) - Contains all verified terminal execution screenshots (`.png`) and raw output transcripts (`.txt`) for every experiment.
